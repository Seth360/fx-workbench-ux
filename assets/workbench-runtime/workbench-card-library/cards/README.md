# 新卡片交付区

规范版本：`ai-workbench-ux@1.5.8`。

每张新卡片建立独立目录：`cards/<lowercase-kebab-case>/`。

富页头仅用于一级工作区页面；详情、列表等二级下钻页面使用 `.wb-secondary-page`，不渲染页面级富页头，直接从记录卡、首个业务指标卡或列表首卡开始。

Rich Header 角色可见头部外溢统一为 `36px`，卡片与顶栏保持 `42px` 顶部间距；窄屏筛选组与复合下拉必须位于角色图上层且不得被页头或相邻卡片裁切，简约模式隐藏角色且不增加特殊间距。编辑态拖拽命中需跳过隐藏按钮与缩放手柄，嵌套网格四方向均可重排。

最低交付内容：

- `index.html`：可直接预览的卡片或集成示例。
- `card.css`：仅放该卡片特有样式，必须引入 `../../components.css`。
- `card.js`：仅在存在交互时创建，不内嵌业务密钥或真实用户数据。
- `README.md`：记录业务来源、数据字段、交互、变体和验证视口。

组合卡内部业务模块必须使用 `.wb-subpanel`，紧凑事实块使用 `.wb-inner-tile`；二者读取共享实底 Surface 与浅层级 Shadow，禁止再次启用背景模糊。宽表固定操作列必须使用完全不透明的 `.wb-action-column` Surface，并使用 32px 高的 `.wb-primary-action`。

快捷新建浮层可用按钮整体 `opacity` 控制 hover/focus 显隐，但显示时必须读取不透明强调色 Surface，禁止被暗色卡片或子面板背景覆盖。

画布主题风格默认“丰富”；显式“简约”通过共享 `data-wb-style="minimal"` 职责 Token 将普通顶层主卡改为实底描边，并让标题、指标和快捷入口图标使用淡色纯色底、弱描边且无渐变/投影/发光。暗色简约仍使用深色 Surface；明确设计为深色的重点卡必须增加 `.wb-special-dark-card`，不能被白化。

数据密集型洞察页的文字操作命令使用 32px `.wb-compact-action`，不得套用到页签、筛选、开关或仅图标按钮。单条上下文事实带四项指标时，上下文独占首行作为标题，四张语义色软底指标卡置于下一行并按容器降列，后续判断区不得重复该摘要。子面板底部口径说明使用灰色圆角元信息 Surface 且不显示顶部描边；未完整字段覆盖标签只用橙色文字；圆形数量徽标的说明必须完整留在圆环内。

金额指标使用钱包、钱币或钞票等 `.wb-semantic-icon` 纯图形 SVG，报价申请使用文档或剪贴板图标。禁止用元、¥、$、货币代码或其他可见字符作为图标；把字符轮廓转换成 SVG path 也不例外。

紧凑经营摘要统一使用 `.wb-compact-baseline-card`、`.wb-baseline-head-copy + .wb-baseline-meta` 和共享 `.wb-metric-grid`，不得另建带大段空白和重复内边距的页面私有指标组件。

页头周期与枚举筛选必须放入 `.wb-page-control-group`，桌面端按内容宽度左右排列且禁止换行；窄屏保持同排并允许组内横向滚动。两个组件与页头紧凑文字命令统一为 32px 高度。

列表结果分组使用 `.wb-filter-segmented` 的透明无投影结构，禁止用页签式 `.wb-segmented` 造成白底或白字反白。列表状态统一用内容宽度、22px 高的 `.wb-status-tag`；负责人使用 `.wb-person-label > .wb-avatar`，确保 14px 语义 SVG 在 22px 强调色圆形背景中以亮色双轴居中。贴边卡的 `.wb-flush-head` 与 `.wb-flush-body` 必须是直接子项，避免正文标准内边距失效。

工作台卡片需要进入列表、客户详情型洞察或商机详情型洞察时，使用 `data-wb-route` 与共享 `workspace-routing.js`；合法的显式目标优先于动作文案推断。表格实体值使用 `.wb-entity-link`，只让字段值本身可点击；列表返回来源工作台。新建、处理、维护、填写等业务命令不得挂载页签路由。

模板组合页使用 `home`、`detail`、`list` 三个稳定工作区键：经营类来源页签合并到“首页”，客户/商机洞察合并到“详情页”，列表页不合并。若页面同时提供 CRM 外框，使用设置按钮左侧的“显示CRM导航”开关切换完整原有顶栏/左栏容器，并将开关状态写入画布配置。

CRM 外框启用时不得锁死画布高度或由 `overflow:hidden` 裁切内容；长页面必须由文档滚动。设置抽屉打开时，画布通过右侧让位空间收窄，避免抽屉覆盖工作台正文。

合并后的首页与详情页直接承载来源卡片，不再渲染来源页内子页签、页头和额外分组表面；同一业务队列、摘要事实和身份记录只保留一个权威卡片，来源卡片按稳定键平铺到当前工作区，列表页继续独立保留。

收到“按照 Skill 美化/优化/调整现有 HTML”等宽泛要求时，把来源 HTML 视为业务与交互证据，从 bundled canvas 与共享卡片结构重新生成完整 HTML；不得只追加页面私有 CSS、包裹旧 DOM 或沿用不完整运行时。仅当用户明确限定为局部修复、保留 DOM 或最小改动时才增量编辑。

交付前必须确认主卡片实际引用 `ai-workbench-ux@1.5.7` 的当前色系弱画布、半透明 Surface、玻璃模糊、白色弱边框和同色系轻阴影；内部子面板不得重复应用玻璃效果。同排卡片必须自然等高，并支持 6 套色系、中文/英文和浅色/深色模式。页面级页头使用 `.wb-header > .wb-title-group` 的单列结构保持标题在上、说明在下；34px 图标列只用于卡片标题，禁止页面标题逐字竖排。顶部工作台页签的有底色列表必须按页签内容收缩，末端工具独立靠右，窄屏仅列表横向滚动。深色指标、快捷入口、元信息和表格必须读取共享深色 Surface，禁止混入 white 或浅色半透明值；暗色控件不得保留顶部白色 inset 高光。所有图标必须按标题、操作或状态语义选择现有 SVG/统一图标库图标，禁止用中文、英文、字母缩写、数字或标点等可见文字生成或代替图标。所有命中的业务语义必须按 `SEMANTIC_COMPONENTS.md` 同时声明 `data-wb-semantic`、`data-wb-component`、ARIA 与字段级元数据，暗色状态通过 `data-theme="dark"` 激活共享 Token。来源包含行业/部门等分布时必须保留可操作的维度切换和逐行数据；独立比率必须显示名称，紧凑指标使用低透明语义底色，列表下钻使用数量胶囊与 SVG 箭头且不重复目的地文案。枚举筛选使用 `.wb-select` 与 `select-interactions.js` 的圆角轻投影弹层，保留原生 `select` 值和 `change` 事件并支持完整键盘操作；工作台页头筛选同时使用 `.wb-page-filter`，确保所有页签的页头周期与枚举筛选在 `.wb-page-control-group` 中左右排列并统一为 32px，以 `var(--wb-page-header-control-height, 32px)` 保证另存后高度稳定。同一业务链路的紧凑分析放入一个父卡，子标题使用语义 SVG，四项紧凑指标保持两列；队列数量使用标题同行纯数字胶囊，多操作行放在正文下方，快捷新建在 hover/focus 时覆盖数值，柱图图例置顶居中，宽表快捷处理列固定最右并使用强调色按钮。同类快捷入口统一为 64px 高、16px 网格间距和 10px 图标文案间距；紧凑阶段/进度行统一为 32px 高和 4px 间距；标题与说明保持上下结构，单一处理入口放在正文右侧同一行。拉丁字母与数字必须 Inter 优先；两行分析布局按需使用紧凑下排；带分隔线的贴边标题卡必须使用 `.wb-flush-card` 结构清除重复外层内边距；跨页签组合必须使用 `.wb-card-composition` 与唯一 `data-wb-card-key`，禁止同一业务队列重复挂载；布局编辑必须由设置面板打开状态驱动，页面大区块与内嵌卡片均使用稳定键/编辑范围，并持久化跨网格归属与顺序；含柱图、饼图或环图时必须接入共享图表浮层、键盘 focus、1000ms 入场动效和 reduced-motion 降级。所有图表必须使用 `.wb-chart-frame` 或等价边界容器留在卡片内；包含文字、圆点、图标或固定描边的 SVG 禁止非等比缩放。相邻权威记录已显示同一身份时，删除经批准的重复身份区，只保留 `.wb-summary-metric-grid` 指标卡；上下游按 `.wb-relation-flow` 纵向连接，三分支用 `.is-three-way` 精确连接三个节点；成对分析在实际容器足够宽时使用共享 6/12 + 6/12 或 5/12 + 7/12。页头中的紧凑文字操作组必须横向无换行，按钮统一为 32px。

生成页出现设置抽屉时，必须同步保留隐藏卡片运行时、持久化字段和编辑引导 Token；不得用可见字符、缩写或数字充当图标，也不得用页面私有筛选组件替代共享复合下拉。收到 UI 反馈后，先按 runtime、token-component、card-adapter、data-only 分层记录证据，再回写规范和验证门禁。

页面切换只使用左侧顶部 `.wb-workspace-tab-list`，设置抽屉不再重复顶层工作区页签。设置打开时，未选页面仍保持隐藏；隐藏卡片全量持久化，但计数和“还原本页”仅作用于顶部页签选中的当前页。

本版本补充 Rich Header 与编辑态回归门禁：角色可见头部外溢为 `36px`，卡片与顶栏间距为 `42px`；窄屏筛选组/下拉位于角色图上层且不被相邻卡片裁切；拖拽命中需跳过隐藏按钮与缩放手柄，嵌套网格四方向均可重排。

丰富主题的页面页头使用 `.wb-rich-header-card`：标题/说明在左上、周期/枚举或紧凑命令在左下，所选 `role-image` 形象在右侧底部贴齐；简约主题隐藏形象并恢复紧凑布局。头部卡片设置必须使用共享复合下拉、默认 `总监.png`、保留八个真实文件名，并在独立 HTML 中内联全部 PNG。

桌面 Rich Header 必须按每张 PNG 的透明头顶留白校准形象尺寸，使可见头部高出卡片顶边 26px；八张资源映射七套服装色浅渐变并随角色切换，“用户/销售”共用粉色系。页头复合下拉打开时必须临时解除 `.wb-page-control-group` 的 overflow 裁切，关闭后恢复窄屏横向滚动。

可单独分发的画布必须通过 `scripts/build_standalone_canvas.mjs` 内联当前共享 CSS、卡片渲染器、路由、复合下拉与图表交互，并通过 `scripts/verify_standalone_canvas.mjs` 的孤立复制回归；禁止交付只能依赖原目录结构才能显示完整页签的 HTML。

禁止直接在 `cards/` 根目录放散落的 HTML/CSS/JS 文件。

目录布局采用 `wb-library-*`：独立用途分组、自然等高预览、容器响应式指标、可搜索语义合同。维护目录时同步 `cards/catalog-examples/` 和 `templates/catalog-item.html`，业务示例不得删减字段。
