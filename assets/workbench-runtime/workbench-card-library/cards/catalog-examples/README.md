# 规范目录示例

`../../index.html` 是目录入口；本目录存放五个当前模板的组合样式、偏好状态和目录交互，并负责介绍页、复合卡片视图与 AIPaaS 基础组件页之间的可访问切换。用途导航只保留“介绍 / 主题色配置 / 指标与分析”，复合卡片是 AIPaaS 分组内 AI Agent 下方的最后一项；介绍页不重复指标分组，指标与分析视图不渲染首页介绍、统计或行业示例，指标卡和复合分析卡均以 `.is-wide` 通栏展示。AIPaaS 欢迎卡片结构位于 `../aipaas-foundations/`。共享文档外框、预览容器、主题职责和配色色块位于 `../../components.css`、`../../tokens.css`。

- `card.css`：图表与列表组合、筛选示例分组、目录色系菜单。
- `preferences.js`：保留既有 `ai-workbench-ux-catalog` 存储键、六色系、中英文、深浅色及简约/丰富。
- `catalog.js`：按用途筛选、模板锚点、复合卡片导航、从预览 DOM 提取语义说明和复制结构。

复制结构是组件片段，需在宿主中引用公共 CSS、SVG sprite 和使用到的 select/chart 运行时。示例 AI/CRM 命令保留入口，但未连接业务服务，不会执行真实写入。
