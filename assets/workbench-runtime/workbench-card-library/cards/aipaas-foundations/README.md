# AIPaaS 组件基础组件

规范版本：`ai-workbench-ux@1.6.38`。

本目录承载规范目录中的 AIPaaS 基础组件导航与完整样式谱系。导航顺序固定为：欢迎卡片、AI 洞察、对象入口、信息列表卡片、对象列表、文本、按钮、图片、AI Agent、复合卡片。“主题色配置”作为独立目录页放在“介绍”导航下方，不再属于 AIPaaS 页面序列。

AI 识别诊断卡中的建议摘要使用共享 `--wb-ai-insight-border: rgba(79, 104, 255, 0.20)` 的 `1px solid` 描边和 `--wb-ai-insight-surface` 的 `96deg` 白色到淡蓝渐变；警告橙仅用于明确的风险文字或状态，不默认铺满建议背景。

两张 AI 洞察示例都使用共享 `.wb-ai-generation-meta`，直接显示 `yyyy-mm-dd HH:MM` 模拟时间与 32px 重新生成图标，不显示“生成时间”文字标签。时间统一为 `--color-neutrals11`、`Source Han Sans CN`、12px/18px、400 字重并关闭连字；第一张卡移除辅助归纳 kicker 并把元信息放在左下，第二张卡保留标题栏右侧位置并以该组合替换总事件胶囊。按钮移除背景、边框和阴影，只显示已批准的 16×16 双路径刷新图形，保留双语 ARIA、键盘焦点、深色可读 Token 和目录未接服务演示反馈。

- `card.css`：九个 AIPaaS 页面与独立主题色配置页的共享布局，不覆盖业务组件 Token；信息列表卡片的共享样式和字段元数据同步位于 `../information-list-card/`。
- `index.html`：可单独打开的欢迎卡片结构预览。
- `source-component-coverage.md`：用户截图、画布注释、角色资源和 Figma 节点到组件结构的来源覆盖清单。
- 信息列表卡片在同页纵向展示 01 待办、02 提醒、03 关注三张同构卡片；来源总数分别为 6、5、未给出，页面不再提供内容页签。右侧时间、状态与类型使用共享胶囊，今天和风险分别高亮。
- 目录页完整实现 AI 洞察 2 种、对象入口 3 种（左右完整、左右名称型、上下名称型）及独立的 390px 移动端适配展示、对象列表 4 种、文本 8 级、按钮 7 类、角色图片 8 个、行业色系 6 套及 AI Agent 对话入口；AI 经营结论卡用 `.wb-ai-generation-row` 在宽容器中把左侧生成时间/重新生成与右侧三个操作垂直居中于同一底部行，并在窄容器安全分行；对象入口使用共享 `.wb-object-entry-*` 结构，不展示上下完整型，完整型保留场景与数字，名称型只显示图标和对象名称，上下名称型在宽目录容器中一行五个并在窄容器响应式降列；移动端完整模式保持单列五项，精简模式固定一行五项，图标在上、名称在下、网格无间距，入口与图标均无背景、描边、圆角、阴影或身份色，DOM 只渲染图标与对象名称，同时保留原按钮、合法路由、ARIA、至少 44px 点击高度与焦点状态；报价管理使用可见的剪贴板 SVG。对象列表与复合卡片一级标题使用 `.wb-title-group.is-iconless`，内部业务子面板仍保留语义图标。文本标题使用可见层级线 SVG，行业推荐为“行业配色建议”六行三列，配色名称旁使用共享 Token 色块并提供推荐理由；AI Agent 使用 `fx-avatar.png`、桌面 24px/34px（移动示例 18px/26px）、400 字重的欢迎语和共享 `.wb-agent-composer`，包含智能体/`Deepseek-V4-Flash`、附件、语音和动态发送动作，不包含建议问题区，业务事实只使用可核验来源。

验证覆盖 `1440x900`、`1024x768`、`390x844`，以及中英文、浅色/深色、简约/丰富和六色系。所有枚举控件继续使用原生 `select` 作为值和 `change` 事件来源。
