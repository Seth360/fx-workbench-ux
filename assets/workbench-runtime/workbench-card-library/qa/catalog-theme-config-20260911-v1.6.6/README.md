- 1440x900、1024x768、390x844。
- 中文/英文、浅色/深色、简约/丰富、六套色系。
- 144 个模板目录状态、144 个主题色配置状态与 1152 个 AIPaaS 页面状态。

- 主题色配置标题、六套色系、行业工作台示例及两个 `_blank` 外链。
- 点击主题色配置导航后，“行业工作台示例”标题处于当前视口内，不被自动滚动跳过。
